# 1. Deskripsi Project

Website Kesenian Giri Adiwarna merupakan website resmi organisasi Kesenian Giri Adiwarna SMKN 1 Banjar.

Website ini dibuat untuk menggantikan sistem administrasi manual menjadi sistem digital sehingga seluruh kegiatan organisasi dapat dikelola secara lebih rapi, aman, cepat, dan profesional.

Website ini bukan hanya sebagai media informasi, tetapi juga sebagai sistem informasi organisasi yang dapat digunakan langsung oleh pengurus maupun anggota.

---

# 2. Tujuan Project

Website dibuat untuk:

- Menjadi identitas resmi organisasi
- Menampilkan informasi terbaru
- Menyimpan sejarah organisasi
- Menyimpan sejarah kepengurusan
- Menampilkan dokumentasi kegiatan
- Mengelola absensi digital
- Mengelola kas anggota
- Mengelola data anggota
- Mengelola pengumuman
- Mengelola event
- Menampilkan prestasi organisasi
- Menyimpan seluruh aktivitas penting melalui Audit Log
- Mempermudah pembuatan laporan

# 16. Alasan Memilih Laravel Blade

Project ini menggunakan Laravel Blade karena:

- Lebih mudah dipelajari
- Hanya menggunakan satu project
- Tidak perlu membuat API terpisah
- Tidak perlu React atau Next.js
- Development lebih cepat
- Mudah dipelihara
- Hosting lebih murah
- Sangat cocok untuk organisasi sekolah
- Tetap terlihat profesional
- Sangat cocok dijadikan Portfolio

---

# 17. Target Project

Target akhir project ini adalah membangun sistem informasi organisasi kesenian yang benar-benar dapat digunakan oleh Kesenian Giri Adiwarna SMKN 1 Banjar.

Website ini diharapkan mampu menggantikan proses administrasi manual menjadi digital sehingga organisasi menjadi lebih modern, efisien, dan profesional.

Selain digunakan oleh organisasi, project ini juga akan menjadi portfolio utama developer pada GitHub, LinkedIn, Portfolio Website, PKL, maupun proses melamar pekerjaan di bidang Web Development dan Software Engineering.
