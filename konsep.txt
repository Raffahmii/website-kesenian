# 1. Deskripsi Project

Website Kesenian Giri Adiwarna merupakan website resmi organisasi Kesenian Giri Adiwarna SMKN 1 Banjar yang dibangun untuk menggantikan sistem administrasi manual menjadi sistem digital.

Website ini tidak hanya berfungsi sebagai media informasi kepada masyarakat, tetapi juga sebagai sistem informasi organisasi yang dapat membantu seluruh pengurus menjalankan tugasnya dengan lebih efektif, cepat, aman, dan profesional.

Melalui website ini seluruh data anggota, kepengurusan, absensi, kas, dokumentasi, prestasi, pengumuman, dan kegiatan organisasi dapat tersimpan dalam satu database sehingga lebih mudah dikelola dibandingkan menggunakan buku tulis ataupun file yang terpisah-pisah.

Website ini dirancang sebagai project portfolio sekaligus aplikasi yang benar-benar dapat digunakan oleh Kesenian Giri Adiwarna.

# 9. Kenapa Memilih Laravel Blade

Project ini menggunakan Laravel Blade karena lebih sederhana dibandingkan memisahkan frontend dan backend.

Dengan Blade seluruh halaman website dapat dibuat langsung menggunakan Laravel sehingga proses development menjadi lebih cepat dan lebih mudah dipelajari.

Laravel Blade juga memiliki performa yang baik, mudah dipelihara, biaya hosting lebih murah, serta sangat cocok digunakan untuk project organisasi sekolah.

Blade tetap mampu menghasilkan tampilan modern dengan bantuan Tailwind CSS dan Alpine.js tanpa harus menggunakan React atau Next.js.
